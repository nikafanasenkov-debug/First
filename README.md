# Игра «Жизнь» Конвея (Game of Life)

Компьютерная модель клеточного автомата, реализованная на Python с использованием библиотек **NumPy**, **SciPy** и **Matplotlib**. Программа демонстрирует пять классических сценариев эволюции клеточного поля: от случайного заполнения до бесконечно работающего ружья Госпера.

---

## 1. Краткое описание модели

**Игра «Жизнь»** — это клеточный автомат, придуманный математиком Джоном Конвеем в 1970 году. Это дискретная модель, в которой эволюция системы определяется начальным состоянием и набором простых правил.

### Правила игры
Каждая клетка поля может находиться в одном из двух состояний:
- **Живая** (значение `1`)
- **Мёртвая** (значение `0`)

На каждом шаге (поколении) состояние клетки определяется числом её живых соседей (8 клеток вокруг):
1. **Рождение:** мёртвая клетка с ровно **3** живыми соседями становится живой.
2. **Выживание:** живая клетка с **2 или 3** живыми соседями остаётся живой.
3. **Смерть:** во всех остальных случаях (менее 2 или более 3 соседей) клетка умирает.

### Уравнение шага (математическая модель)

Пусть `G` — текущее состояние поля (матрица N×N, где `G[i,j] ∈ {0, 1}`).
Пусть `K` — ядро свёртки (матрица 3×3, центр = 0, все остальные = 1):

```
K = | 1  1  1 |
    | 1  0  1 |
    | 1  1  1 |
```

Тогда число живых соседей для каждой клетки вычисляется как **свёртка**:

```
N(i,j) = Σ  G(i+dx, j+dy) · K(dx, dy)     для dx, dy ∈ {-1, 0, +1}
```

Затем применяются правила перехода:

```
G_new(i,j) = 1,  если (G(i,j) = 0  и  N(i,j) = 3)          — рождение
G_new(i,j) = 1,  если (G(i,j) = 1  и  N(i,j) ∈ {2, 3})     — выживание
G_new(i,j) = 0,  во всех остальных случаях                 — смерть
```

### Реализация на Python

Модель реализована с помощью **векторизации** и **свёртки** (`scipy.signal.convolve2d`). Вместо перебора каждой клетки в цикле `for` используется математическая операция свёртки с ядром 3×3, что даёт ускорение в 50–100 раз по сравнению с классической реализацией.

**Код функции `step()`:**

```python
kernel = np.array([[1, 1, 1],
                   [1, 0, 1],
                   [1, 1, 1]])

def step(grid):
    neighbors = convolve2d(grid, kernel, mode='same', boundary='fill', fillvalue=0)
    birth     = (grid == 0) & (neighbors == 3)
    survival  = (grid == 1) & ((neighbors == 2) | (neighbors == 3))
    return (birth | survival).astype(int)
```

Здесь:
- `convolve2d(...)` — вычисляет `N(i,j)` — количество живых соседей для всех клеток сразу;
- `boundary='fill', fillvalue=0` — клетки за пределами поля считаются мёртвыми;
- `birth` — булева маска клеток, которые родятся;
- `survival` — булева маска клеток, которые выживут;
- `birth | survival` — итоговое новое состояние поля.

## 2. Возможности и ограничения

### ✅ Возможности
- Пять независимых сценариев эволюции поля (см. раздел 4).
- Автоматическое сохранение каждой симуляции в отдельный **GIF-файл**.
- Цветовая визуализация: каждая связанная фигура (планер, ружьё, осциллятор) автоматически получает свой уникальный цвет.
- Декодер **RLE** (Run Length Encoding) для загрузки паттернов из LifeWiki.
- Пошаговый показ анимаций с ожиданием закрытия окна.

### ⚠️ Ограничения
- Поле имеет **конечный размер** (`N = 200`). Клетки за пределами поля считаются мёртвыми (`boundary='fill'`).
- Корабли и планеры, улетающие за край поля, **исчезают** и не возвращаются (нет зацикливания).
- Все паттерны (ружьё, корабли) заданы **жёстко** в коде, без интерактивного ввода.
- Модель работает **только в 2D** и **синхронно** (все клетки обновляются одновременно).
- Ружьё Госпера имеет **период 30 поколений** — новый планер появляется каждые 30 кадров.

## 3. Инструкция по запуску

### Требования
- Python **3.8+**
- Установленные библиотеки:
  - `numpy`
  - `scipy`
  - `matplotlib`

### Установка зависимостей
Откройте терминал в папке проекта и выполните:
```bash
pip install numpy scipy matplotlib
```

### Запуск
```bash
python game_of_life_all.py
```

### Что произойдёт
1. Программа поочерёдно запустит **5 симуляций**.
2. Для каждой симуляции:
   - Создастся GIF-файл (например, `cycle_1_random.gif`).
   - Откроется окно с анимацией.
   - **Программа будет ждать**, пока вы не закроете окно.
3. После закрытия окна автоматически запустится следующая симуляция.
4. В конце все 5 GIF-файлов будут лежать в папке с проектом.

### Дополнительные параметры
Все параметры задаются в начале скрипта:

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `N` | `200` | Размер поля (N × N клеток) |
| `ON` | `1` | Значение живой клетки |
| `OFF` | `0` | Значение мёртвой клетки |
| `frames` | зависит от цикла | Количество поколений (кадров) |
| `interval` | `100` | Задержка между кадрами (мс) |
| `fps` | `15` | Кадров в секунду при сохранении GIF |

**Пример изменения:** чтобы поле стало 300×300, измените строку:
```python
N = 300
```

**Пример изменения скорости анимации:** уменьшите `interval` до `50` — анимация ускорится в 2 раза.

## 5. Как интерпретировать результаты

### Цветовая схема
- **Тёмно-синий фон** — мёртвые клетки.
- **Яркие цвета** — живые клетки. Каждая **связная фигура** получает свой цвет автоматически с помощью `scipy.ndimage.label`.
- Цвета берутся из палитры `tab20` (20 оттенков).

### Что наблюдать в каждом цикле

#### 🔵 Цикл 1 — Рандом
Из хаотичного начального состояния рождаются устойчивые структуры (блоки, ульи) и осцилляторы. Через ~50 поколений поле стабилизируется — останутся только «выжившие» фигуры. Это демонстрация **самоорганизации** системы.

#### 🟢 Цикл 2 — Неподвижные (Still Lifes)
Фигуры **не меняются** со временем. Их форма остаётся идентичной на каждом кадре. Это пример **устойчивых конфигураций** — «камней» игры «Жизнь».

#### 🟡 Цикл 3 — Осцилляторы
Фигуры **периодически возвращаются** к исходному состоянию:
- **Blinker** — период 2 (горизонтальная линия ↔ вертикальная).
- **Toad** — период 2.
- **Beacon** — период 2.
- **Pentadecathlon** — период 15.
- **Pulsar** — период 3 (один из самых красивых осцилляторов).

Наблюдайте за ритмичным «дыханием» фигур.

#### 🟠 Цикл 4 — Космические корабли
Фигуры **двигаются по полю**, сохраняя свою форму:
- **Glider** (5 клеток) — летит по диагонали вниз-вправо со скоростью 1 клетка за 4 такта.
- **LWSS** (9 клеток) — летит горизонтально вправо.
- **MWSS** (11 клеток) — летит горизонтально вправо.
- **HWSS** (13 клеток) — летит горизонтально вправо.

Три горизонтальных корабля размещены в одной линии (Y=100) с интервалами, чтобы не столкнуться. Глайдер летит отдельно — по диагонали.

#### 🔴 Цикл 5 — Ружьё Госпера
Это **бесконечно работающий генератор**. Ружьё остаётся на месте, но каждые **30 поколений** выпускает новый планер, который летит по диагонали вниз-вправо. Это первое доказательство того, что игра «Жизнь» может **неограниченно расти**.

Каждый новый планер получает свой цвет, поэтому вы увидите «радужную очередь» из летящих фигур.

### Как читать GIF-файлы
- **Количество кадров** соответствует числу поколений.
- **Скорость** задаётся параметром `fps` (по умолчанию 15 кадров/сек).
- Если GIF проигрывается слишком быстро, откройте его в браузере или любом просмотрщике с возможностью замедления.

- **LWSS** — 9 клеток, движется горизонтально.
- **MWSS** — 11 клеток, движется горизонтально.
- **HWSS** — 13 клеток, движется горизонтально.
